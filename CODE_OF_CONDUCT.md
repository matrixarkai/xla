# Code of Conduct

## Our Commitment

Everyone participating in this repository should be able to contribute without
harassment, regardless of age, disability, ethnicity, gender identity or
expression, nationality, personal appearance, race, religion, or sexual identity
and orientation.

Be respectful, give constructive feedback, respect privacy, and welcome people
with different experience and perspectives. Harassment, threats, discriminatory
language, unwanted sexual attention, and publishing another person's private
information are not acceptable.

## Scope and Enforcement

These standards apply to this repository's issues, pull requests, discussions,
and other project spaces. Maintainers may edit or remove inappropriate content,
limit participation, or block repeat offenders using GitHub's moderation tools.
Responses should be proportionate to the conduct and protect affected people.

For abuse or spam, follow
[GitHub's reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
These include reporting privately to GitHub Support; reporting directly to
repository administrators is available only where that option is enabled.
Do not publish private information when making a report.
