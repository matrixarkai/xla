# Security Policy

## Scope

This policy covers the main development branch of the matrixarkai XLA fork.
It does not establish security support commitments for upstream XLA releases.

## Reporting a Concern

Do not publish vulnerability details, exploit code, credentials, or private data
in issues, pull requests, or discussions.

For a concern specific to this fork, open a
[maintainer-contact request](https://github.com/matrixarkai/xla/issues/new)
asking how to arrange confidential security communication. Include no technical
details, affected components, or private data in that public request. Wait for
maintainers to establish a confidential channel before sharing those details.
The issue tracker itself is public, not a confidential reporting channel.

This policy does not promise a response time or a private reporting inbox.
